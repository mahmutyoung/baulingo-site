# DTZ website implementation plan

Goal: bring the existing original DTZ Mock Exam 01 to the main Baulingo website as a free, usable resource for attracting Turkish-speaking learners.

Architecture: static, indexable `/dtz-deneme-sinavi/` page with native JavaScript enhancement. Reuse approved fonts, cream/sage palette and shared navigation. German source material stays unchanged; surrounding instructions are Turkish. Content, pure exam rules and DOM rendering remain separate. No app edits, framework, account, backend or new tracking provider.

Source: sibling `german-exam-app/src/features/mock-exam/dtzMockExam.ts` and its three media files, checked against Obsidian `Projects/Mock Exam/Content`. The editorial README identifies these as original tasks/media, not an official examination. It recommends human assessment and audio review; do not claim that this port supplies such approval.

Approach: a native web player reusing the data/media is appropriate to this static website. An Expo export would bring unrelated app material and dependencies. A PDF-only resource would omit the requested simulation. The user approved a separate lazy-loaded media allowance after inspection found 8.7 MB of audio.

Constraints: retain 2,000,000-byte core output limit, add 10,000,000-byte DTZ media allowance for explicit audio/images. Audio has no source until the learner starts listening. Media stays in the main free static deployment, outside the initial homepage download. Never copy whole app/vault directories or credentials. Prior analytics work in the dirty workspace must be preserved. No commit, push or deployment is authorized by this implementation request.

## Review focus

- Background/reload must not grant extra reading/writing time or grade unsubmitted sections.
- Tampered/corrupt local state must not crash, overwrite a valid attempt silently or inflate scores.
- Audio failures must explain recovery without creating a fake completed listening section.
- All content and task navigation must remain readable and operable on narrow screens and keyboards.
- Score labels must never imply an official DTZ result or assessed speaking/writing level.

## Decisions and evidence

- Source app has 20 listening + 25 reading items; examples are explicitly separate. Reading and writing use absolute deadlines. Score bands are below A2 / A2 / B1 for receptive skills only.
- Official format/threshold reference checked: https://www.gast.de/de/forschung-entwicklung/entwicklung/auftraege/deutsch-test-fuer-zuwanderer-dtz/der-dtz-auf-einen-blick
- User approved the separate media budget and was told it remains on free hosting.

Completion evidence: 25/25 automated tests and full browser/edge-case checks passed. A fresh read-only reviewer independently ran 5/5 pure tests and reported no important bugs. No app changes, commit, push or deployment. Screenshots/results are in ignored `.dev/`.
