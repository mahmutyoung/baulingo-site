# DTZ writing studio

The owner supplied [this studio reference](dtz-writing-studio-reference.png) on 13 November and requested its compact, easily navigable style, minimal visible instructions and a visible sentence-pattern toolbox. Educational content must not change.

The existing website fonts, logo, ivory/forest/sage/gold palette and static routes remain authoritative. The reference informs the three-column composition: grouped lesson navigation, a focused working area, and a tool/preview rail. The pictured sample steps and sentences do not replace the course's actual tasks.

After discussing the target audience's preference for simple formats, the owner approved a guided letter builder on branch `codex/guided-letter-builder`. The primary route is “Birlikte yazalım”. Non-simulation full-letter tasks use nine steps: greeting, introduction, the four original points, closing, name and editable review. One clear label and field appear at a time, with Geri / Devam et. Task navigation uses descriptive names. Original Turkish teaching text is split into list items without rewriting it; German model letters retain normal formatting.

A letter-shaped preview groups the learner's answers under visible section labels, highlights the current section and allows returning to it. On phones “Mektubumu gör” expands the preview. Three relevant patterns from the existing 64-entry reference appear beside the field; the complete searchable toolbox remains available during writing and final review. MIT-licensed Tabler outline icons accompany visible labels (recipient, date/time, cost, sentence help, letter and closing). Icons carry no independent instructions or automatic correctness claims.

Original instructions, plans, checks, models, explanations and revision fields remain accessible. Independent/timed simulation retains its full-letter editor. Older full drafts open intact in review. Section work is saved separately; generated drafts track section edits while independent full-letter edits are preserved. Explicitly transferring sections into an independently edited letter retains the previous full text. Export includes sections and the previous draft, including when persistent storage is unavailable.

The course retains all 24 destinations, 47 task IDs, 22 learning lessons and two reference tools. Progress, answers, drafts, A/B choices, clocks and export use the existing player and rules. Without JavaScript, the static lesson/task/model content and reference links remain accessible. Changes are local pending owner review and separate publication authorization.
