# DTZ writing studio

The owner supplied [this studio reference](dtz-writing-studio-reference.png) on 13 November and requested its compact, easily navigable style, minimal visible instructions and a visible sentence-pattern toolbox. Educational content must not change.

The existing website fonts, logo, ivory/forest/sage/gold palette and static routes remain authoritative. The reference informs the three-column composition: grouped lesson navigation, a focused working area, and a tool/preview rail. The pictured sample steps and sentences do not replace the course's actual tasks.

Learning stages and numbered task buttons show one working context at a time. Full task instructions, plans, checks, model answers, explanations and revision fields remain in expandable sections. The right rail offers the existing 64 phrases, Turkish meanings and examples, search, cursor insertion and a live preview of the learner’s draft. On phones the toolbox is an expandable section above the work area; inserting a phrase returns focus to the editor.

The course retains all 24 destinations, 47 task IDs, 22 learning lessons and two reference tools. Progress, answers, drafts, A/B choices, clocks and export use the existing player and rules. Without JavaScript, the static lesson/task/model content and reference links remain accessible. Changes are local pending owner review and separate publication authorization.
